# Pokémon System

## Sobre o projeto

O Pokémon System é um sistema de gerenciamento de Pokémon desenvolvido em Python.

O objetivo é permitir que o usuário cadastre, consulte, edite, pesquise e exclua Pokémon por meio de uma interface gráfica intuitiva.

O projeto utiliza conceitos de Programação Orientada a Objetos (POO), organização de código em módulos e integração com banco de dados.

## Funcionalidades

- Cadastro de Pokémon.
- Consulta e listagem de Pokémon cadastrados.
- Edição das informações dos Pokémon.
- Exclusão de registros.
- Pesquisa de Pokémon.
- Armazenamento das informações em banco de dados.
- Busca e armazenamento de imagens dos Pokémon por meio de uma API.

## Tecnologias utilizadas

- **Python:** linguagem utilizada no desenvolvimento.
- **Tkinter:** criação da interface gráfica.
- **SQLite:** gerenciamento e armazenamento dos dados.
- **PokeAPI:** obtenção das imagens dos Pokémon.

## Organização do projeto

O sistema foi desenvolvido com separação de responsabilidades, utilizando Programação Orientada a Objetos (POO).

- **Interface:** responsável pela interação com o usuário.
- **Classes:** responsáveis pela organização e representação dos dados.
- **Banco de dados:** responsável pelo armazenamento das informações.
- **Conexão:** responsável pela comunicação entre o sistema e o banco de dados.
